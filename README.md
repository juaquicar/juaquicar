## 🏛️ Proyecto destacado: [Sevilla y Aljarafe, edificio a edificio](https://github.com/juaquicar/sevilla-aljarafe-edificio-a-edificio)

Visor 3D con los **179.516 edificios** de Sevilla y los 32 municipios del Aljarafe, coloreados por época de construcción.
Datos del Catastro, el patrimonio del IAPH y Wikidata, el relieve del IGN y OpenStreetMap; pipeline en Python y visor three.js.
